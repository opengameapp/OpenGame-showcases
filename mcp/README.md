# OpenGame MCP Servers

This directory contains source-controlled, public MCP servers that complement
OpenGame's public skills and browser-game showcases.

| Server | Purpose | Distribution status |
| --- | --- | --- |
| [OpenGame Browser Game MCP](opengame-browser-game-mcp/) | Local tools for game-blueprint planning, runtime selection, brief validation, and public Showcase discovery. | Source ready; npm and registry publication pending. |

Every server must be independently useful, runnable without production
credentials, explicit about local versus remote behavior, and tested before it
is submitted to an MCP directory. Do not add production endpoints, customer
data, private prompts, analytics, or credentials here.
